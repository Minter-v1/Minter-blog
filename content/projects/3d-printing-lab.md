## 서비스 소개

- 국립한밭대학교 스마트 3D프린팅 연구소의 공식 웹사이트
- 적층제조(PBF · DED · Plastic) 기술, 보유 장비, 교육, 연구 활동을 외부에 소개
- 주요 메뉴
  - 연구소 소개 · 수행 과제
  - 핵심 기술 (PBF, DED, PLASTIC, 시험·분석, 설계·해석)
  - 산업별 적용사례
  - 장비 및 시설 (분류별 보유 장비)
  - 전문 교육
  - 소식 및 자료, 연구실 활동 게시판

## 수행 내용 (R&R)

| 영역 | 담당 |
| --- | --- |
| 요구사항 반영 | 연구소의 기획·디자인 요구사항을 웹 화면과 기능으로 구현 |
| 화면 구현 | 소개·기술·적용사례·장비·교육·소식 페이지, 분류 탭 전환, 반응형 레이아웃 |
| 데이터 연동 | Next.js 서버 사이드에서 AWS DynamoDB를 연동해 게시물·장비 등 데이터 조회·관리 |
| 파일 업로드 | AWS S3 연동으로 활동 사진 등 이미지·파일 업로드 |
| 콘텐츠 관리 | 로그인 기반으로 연구원이 연구실 활동을 직접 게시하는 흐름 |
| 운영 | 오픈 이후 2025년 12월까지 운영 대응 |

## 결과

- 연구소 공식 사이트 오픈, 현재 운영 중
- 연구원이 직접 활동 기록을 올리는 게시판으로 연구실 활동 아카이브 구축 (2023 ~ 2026 게시물 누적)
- 장비·기술·교육 정보를 분류별로 정리해 외부 기관·기업 대상 소개 창구로 활용
