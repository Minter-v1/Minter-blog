> 국립한밭대학교 스마트 3D프린팅 연구소의 공식 웹사이트를 외주 SI로 구축하고, 오픈 이후 운영을 맡았다.

> 회사 작업물이므로 코드와 내부 구현 세부는 공개하지 않고, 공개된 화면과 수행 범위를 중심으로 정리했다.

| 항목 | 내용 |
| --- | --- |
| 소속 | 스마트뉴비 SW팀 (프론트엔드 인턴), 외주 SI 프로젝트 |
| 발주처 | 국립한밭대학교 스마트 3D프린팅 연구소 |

| 형태 | 4인 팀 |
| 역할 | Full-stack · 운영 |
| 담당 범위 | 화면 구현, 서버 사이드 데이터 연동, 파일 업로드, 운영 대응 |

### 핵심 성과

- 연구소 공식 사이트 오픈, 현재 운영 중 ([hbnu3dp.com](https://hbnu3dp.com/))
- 연구원이 직접 활동 기록을 올리는 게시판으로 2023 ~ 2026 연구실 활동 아카이브 구축

### 주요 기여

- 기획·디자인 요구사항 기반 웹 화면 및 기능 구현
- Next.js 서버 사이드에서 AWS DynamoDB 연동, 데이터 조회·관리
- AWS S3 연동 이미지·파일 업로드

## 1. 프로젝트 개요

### 1.1 배경

스마트 3D프린팅 연구소는 PBF · DED · Plastic 적층제조 기술, 보유 장비, 전문 교육, 연구 활동을 외부 기관과 기업에 소개할 공식 창구가 필요했다. 연구원이 직접 활동을 기록하고 공유할 공간도 함께 요구됐다.

[![스마트 3D프린팅 연구소 메인 화면 (클릭하면 원본)](/projects/3d-printing-lab/home.jpg)](/projects/3d-printing-lab/home.jpg)

### 1.3 목표와 요구사항

- 연구소 소개 · 수행 과제
- 핵심 기술 (PBF, DED, PLASTIC, 시험·분석, 설계·해석)
- 산업별 적용사례, 장비 및 시설(분류별 보유 장비), 전문 교육
- 소식 및 자료, 연구실 활동 게시판

### 1.4 제약 조건

- 회사 작업물로 코드·내부 구현 비공개
- 기획·디자인은 발주처와 협의된 요구사항을 따름

## 2. 시스템 설계

### 2.3 기술 스택

| 분류 | 기술 | 사용 목적 |
| --- | --- | --- |
| 프론트엔드 | Next.js | 페이지 렌더링, 서버 사이드 데이터 처리 |
| 데이터 | AWS DynamoDB | 게시물·장비 등 콘텐츠 데이터 |
| 스토리지 | AWS S3 | 활동 사진 등 이미지·파일 저장 |

소개 · 기술 · 적용사례 · 장비 · 교육 · 소식 페이지를 구현했다. 기술과 장비 페이지는 분류 탭으로 내용을 전환한다.
