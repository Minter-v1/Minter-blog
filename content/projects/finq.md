## 운영 아키텍처

![FinQ AWS 인프라 아키텍처](/projects/finq/architecture.png)

- **AWS 3-Tier**: VPC · ALB · EC2 · RDS
  - 외부 요청은 ALB에서만 수신
  - 백엔드 서버(EC2)와 데이터베이스(RDS)는 내부 영역에 분리
- **백엔드**: Spring Boot(Java 21) 컨테이너, 회원·콘텐츠·학습·보상·알림 API
- **외부 연동**
  - 푸시: Firebase, 알림 동의 사용자 대상 매일 오후 10시 학습 리마인드
  - 이메일: 비밀번호 재설정 메일 발송
  - Slack: 배포 성공·실패 결과, 일일 AWS 비용 보고

## 운영 작업

### 1. 배포 자동화

- **흐름**: `develop` 브랜치 push → GitHub Actions
  1. Spring Boot JAR 빌드
  2. OIDC로 AWS IAM Role 위임 (장기 Access Key 미사용)
  3. 커밋 SHA 태그로 Docker 이미지 빌드 → ECR 푸시
  4. SSM Run Command로 EC2의 배포 스크립트 실행
  5. 명령 완료까지 대기 후 실행 결과(상태·출력·오류) 확인, 실패 시 워크플로 실패 처리
  6. 성공·실패 모두 Slack 알림 (브랜치·커밋·실행자·로그 링크)
- **판단 근거**
  - 커밋 SHA 태그: 어떤 커밋이 운영에 올라가 있는지 바로 추적, 이전 이미지로 되돌리기 쉬움
  - SSM 배포: 배포를 위해 SSH 포트를 열거나 키를 CI에 저장할 필요 없음
  - 배포 단계에 검증과 롤백을 두어 실패한 배포가 서비스에 남지 않게 구성

### 2. 접근 통제

- Bastion 대신 SSM Session Manager로 서버 접속
- 외부 요청 경로(ALB)와 내부 서버·데이터베이스를 분리한 보안 구성
- CI는 OIDC 기반 임시 자격 증명, 저장소에 AWS 키 미저장

### 3. 운영 알림과 비용 관리

- 배포 결과를 팀 Slack으로 공유해 PM·앱 개발자도 반영 시점 확인
- AWS 일일 리소스 비용을 이메일·Slack으로 자동 보고
- 비용 이상을 다음 날 바로 확인할 수 있는 체계

### 4. 운영 데이터 품질

- 한국 시간 기준 학습 날짜 처리, 자정 전후 스트릭 집계 오류 해결
- 로그아웃·알림 해제·유효하지 않은 기기로의 푸시 오발송 방지
- 운영 중 발견된 콘텐츠·이미지·학습 데이터 오류 지속 보정
- 기능 변경 후 기존 화면·데이터 흐름 오류를 막는 자동 테스트 구축

## 코드 작업 내용

- 범위: FinQ-app(Spring Boot) 저장소 커밋 161건 중 **113건 직접 작성** (2026.08.22 ~ 10.02, 머지 커밋 제외)
- 구조: `content` · `learning` · `home` · `reward` · `streak` · `notification` · `backoffice` 도메인 분리, Flyway 마이그레이션 27개, 테스트 클래스 66개

### 기반 구성

- Flyway 초기 스키마와 환경별(local · prod) 설정 구성
- USER 도메인 영속성 구현과 MySQL 영속성 테스트
- JWT 인증 기반 구성, Access Token 재발급, 로그아웃 시 세션 종료
- Refresh Token 만료 시 해당 세션 정리

### 인증과 계정

- 일반 회원가입·로그인, 필수 약관 동의 (약관 저장 실패 시 회원가입 롤백 테스트)
- Kakao 로그인: 액세스 토큰 검증 → 로그인·가입 처리
- Apple 로그인: Identity Token 검증, Authorization Code 검증, nonce 길이 검증
- 기존 회원의 Kakao·Apple 계정 연동, Apple Refresh Token 암호화 저장
- 소셜 계정 연결 해제와 회원 탈퇴 통합, 사용자 종속 데이터 cascade 삭제 (연쇄 삭제 검증 테스트)
- 비밀번호 재설정: 인증번호 전송·확인 → 일회용 토큰 기반 재설정

### 온보딩과 마이페이지

- 온보딩 상태 조회, 관심 주제 최초 저장·수정, 온보딩 완료 처리
- 마이페이지 조회와 프로필 수정 API 분리, 응답 정합성 수정
- 프로필·캐릭터 이미지 URL 매핑, 현재 사용자 프로필 이미지 조회 API
- 닉네임 최대 길이 15자 통일, 관심 주제 요청을 ID 기준으로 정리

### 학습과 보상

- 스트릭 기록 도메인, 계산·보상, 학습 완료 시 스트릭 연동, 조회 API
- 스트릭 일별 통계 저장 구조, 기준일별 집계, 일별 집계 스케줄러
- 홈 추천 질문 3개 반환 보장, 질문형 제목, 캐릭터 이미지 URL 제공
- 게스트(비회원) 지원: 홈, 지식맵·일반 콘텐츠 조회, 일반 학습 문제 채점, 로그인 안내 문구

### 푸시 알림

- 푸시 토큰 도메인, 등록·갱신·해제 API, 알림 수신 설정 변경 API
- Firebase Admin SDK 구성, FCM 발송과 무효 토큰 정리
- 알림 동의 사용자 대상 FCM 배치 발송, 학습 리마인드 스케줄러 (발송 시각 22시)
- FCM 토큰 활성 상태 관리: 로그아웃 시 비활성화·발송 대상 제외, 재등록 검증 테스트
- 알림 선택 시 이동할 학습 화면의 라우팅 데이터 의존성 제거

### API 문서와 계약

- Swagger UI·API 메타데이터 표준화, JWT 인증 설정, 도메인 태그·담당자·응답 상태 enum화

- OpenAPI 3.1 문서 규격 복구, 중첩 스키마 참조 오류 수정
- 공통 응답과 Swagger 계약 불일치 수정, API 필드 계약 회귀 테스트 추가

### 백오피스
