## 1. 프로젝트 개요

### 1.1 배경

치매에 대한 낙인이 환자를 사회에서 멀어지게 한다는 문제의식에서 시작했다. "치매"는 '어리석을 치(癡)'와 '어리석을 매(呆)'로 이뤄진 말로, 환자와 가족에게 모멸감을 주고 질병을 숨기게 만든다. 인터뷰에서 시민들은 "가족에게 짐이 될까 봐", "기억을 잃으면 사회에서 내 존재가 사라질 것 같아서" 두렵다고 답했다. 팀은 용어만 바꾸는 데 그치지 않고, 환자가 존엄성을 유지하며 사회의 일원으로 살아갈 수 있는 움직임을 만드는 것을 목표로 했다.

### 1.2 문제 정의

대덕구 노인종합복지관, 중리 종합사회복지관 관계자와 일반 시민을 인뎁스 인터뷰했다. 그 결과 "개인의 기억을 지키는 일은 결국 모두의 존엄을 지키는 일"이라는 인사이트를 얻었고, 일상의 기억을 기록하고 나누는 기억 아카이빙 프로젝트로 구체화했다.

### 1.3 목표와 요구사항

- 나 · 시간 · 공간 테마의 질문 카드로 기억을 기록
- 실물 카드덱과 웹앱을 연결해 손으로 쓴 기록도 휴대폰에 저장
- 맞춤형 추천부터 기록 분석까지 한 서비스에서 관리

## 2. 시스템 설계

### 2.1 전체 아키텍처

프론트엔드(Next.js)는 Netlify로 배포하고, 백엔드(FastAPI)와 데이터베이스(PostgreSQL)는 NCP 3-Tier 서비스 인프라에 Docker 컨테이너로 배포했다. 실물 카드에 인쇄된 QR이 웹앱의 카드 등록 화면으로 연결된다.

### 2.2 기술 스택

| 분류 | 기술 | 사용 목적 |
| --- | --- | --- |
| 인프라 | NCP, Docker | 백엔드 3-Tier 서비스 인프라, 컨테이너 배포 |
| 배포 | Netlify | 프론트엔드 배포 |
| 프론트엔드 | Next.js | 모바일 웹앱 |
| 백엔드 | FastAPI, PostgreSQL | 카드·기록 API, 데이터 저장 |

## 3. 주요 구현

### 3.1 웹앱 기능

- 온보딩: 사용법 안내 후 회원가입·로그인
- QR 인식: 실물 카드의 QR을 찍어 카드 등록, 휴대폰에서도 기록 저장·확인
- 카드덱: 테마별 질문 선택, 오늘의 카드 기록
- 마이페이지: 카드에 저장한 정보와 기록 확인·수정

[![MOA 웹앱 화면 (클릭하면 원본)](/projects/moa/app.jpg)](/projects/moa/app.jpg)

### 3.2 카드덱 키트 연동

디자인팀이 만든 「나의 기억 MOA 카드」는 나 · 시간 · 공간 · 소통 4개 테마의 질문 카드와 가이드북으로 구성된다. 카드마다 QR을 넣어 웹앱의 해당 카드로 연결했다.
